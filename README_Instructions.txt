Scaled Multi-Block AltGDmin for Robust PCA
=============================================

Instructions
------------

1. Download all MATLAB files from this repository.

2. Keep all the provided MATLAB files in the same folder.

3. Open the main MATLAB script.

4. In the script, you only need to provide the path to the CDnet dataset folder.

   Example:
   datasetFolder = 'C:\path\to\CDnet\dataset';

5. Run the main script.

The code will automatically perform the simulation using the provided dataset path.

Evaluation
----------

After the simulation is complete, the F1 score is calculated using the official CDnet 2012 evaluation code.

Official CDnet Evaluator:
[https://changedetection.net/code/]
